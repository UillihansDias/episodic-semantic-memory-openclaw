# Memory Consolidation

## Purpose
Convert experiences into reusable knowledge without losing evidence or overgeneralising.

## Triggers
Related episodes accumulate; explicit durable preferences emerge; completed tasks produce lessons; decisions establish constraints; existing assertions need revalidation; recurring outcomes suggest patterns. Triggers begin evaluation, not automatic promotion.

## Procedure
1. Select episodes relevant to one topic and scope.
2. Align event chronology and temporal validity.
3. Identify candidate assertions and patterns.
4. Assess original source quality and independence.
5. Seek contradictions and counterexamples.
6. Consider alternative explanations and potential error consequences.
7. Select the narrowest supported assertion.
8. Link it to supporting sources and episodes.
9. Save only if relevant, permitted, and supported.
10. Verify the persistence operation.

## Promotion policy
An explicit authoritative statement may justify immediate semantic capture. Repeated observations may support an inferred, narrowly scoped assertion. Reposts of one original statement are not independent evidence. One failed attempt is not a universal rule.

## Possible outcomes
Create a semantic record; reinforce, narrow, or supersede an existing assertion; mark disputed; reject unsupported promotion; or defer.

## Example
A user requests local storage, prioritises offline use, and rejects a cloud-only architecture for one project. A defensible assertion is that the project requires offline operation. It does not establish that the user dislikes all cloud services.

## Retention and reflection
Keep evidence links and meaningful episodes subject to retention policy. Reflection generates candidate lessons; it does not authorise unrestricted persistence of internal reasoning.
