# Semantic Memory

## Definition
Semantic memory contains durable reusable assertions, concepts, relationships, constraints, and preferences independent of a particular occurrence.

## Assertion model
Represent subject, predicate, object, contextual scope, qualifiers, evidence, and validity period. Example: `Project Alpha → storage_strategy → local-first`, scoped to Project Alpha.

## Categories
Facts, explicit preferences, constraints, definitions, relationships, technical principles, procedural knowledge, inferred patterns, and hypotheses.

## Knowledge status
- Explicit: directly stated by an identifiable source, not necessarily objectively true.
- Verified: checked against suitable authoritative evidence.
- Inferred: derived from evidence by reasoning.
- Tentative: plausibly supported but insufficiently established.
- Disputed: supported and conflicting claims remain unresolved.

## Confidence
Numerical confidence is optional and requires a meaningful policy. Do not conflate source reliability, retrieval relevance, and factual certainty.

## Scope and time
Capture user/project/organisation/environment/domain/time applicability. Missing scope does not make a claim universal. When a fact changes, update the current view and preserve the earlier valid state where justified.

## Negative knowledge and unknowns
Explicit negative constraints are not the same as missing information. Distinguish unknown, unverified, not applicable, false, and historically true but no longer valid.
